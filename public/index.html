    How to set up navigation

    1. Put the robot in a bounded, stair-free area
    2. Click Map This Floor
    3. Robot explores reachable LiDAR frontiers autonomously
    4. Finish Mapping, then review and use the candidate map
    5. Capture verified waypoints after promoting the map

    Step-by-step instructions

    1. Localize on Map

      On a normal session, the app does this automatically. It starts Cartographer in localization mode against the saved map. Click "Localize on Map" if you need to restart it manually.

    2. Map This Floor

      Put the robot in a clear, bounded, stair-free area and click "Map This Floor". It uses LiDAR and Nav2 frontier goals to explore reachable unknown space, then saves a reviewable candidate when you finish.

    3. Drive robot to waypoint spot

      Use manual controls to drive the robot to the exact location where you want a waypoint (e.g., kitchen counter, living room couch). Do not carry the robot â€” Cartographer laser-only localization cannot globally re-localize after being carried.

    4. Wait for pose stable

      Wait until the pose indicator shows "waypointSafe". This means Cartographer has localized the robot reliably on the map.

    5. Save waypoint here

      Enter a waypoint name (e.g., "kitchen") and click "Save Spot". The current pose is saved with the map identity.

    6. Repeat for more waypoints

      Move to each waypoint location and repeat steps 7-9.

    7. Recapture stale waypoints if needed

      If any waypoints show as stale (map identity mismatch), click "Recapture" next to each one and re-save at the correct location.

    8. Restart Nav if needed

      The app auto-starts Nav2 on launch. If the nav-chain health shows Nav2 is down, click "Restart Nav" in the Navigation Setup panel.

    9. Say "go to kitchen"

      Use voice or text to command the robot to navigate to a waypoint. The robot will plan a path and walk there.

    Troubleshooting

    Robot won't start mapping
    • Check LiDAR is connected and spinning
    • Verify DOGZILLA IP is set in Diagnostics drawer
    • Run "Check network" and "Check robot link" in Diagnostics
    Pose not stable (not waypointSafe)
    • Ensure robot is on a flat, stable surface
    • Check LiDAR has clear view of surroundings
    • Wait 10-15 seconds for Cartographer to converge
    • Try restarting map localization in Diagnostics
    Waypoints show as stale
    • Map identity changed (new map saved)
    • Click "Recapture" next to each stale waypoint
    • Re-save waypoint at the correct location
    Nav2 won't start
    • Check navigation chain health dots in Robot Info panel
    • Verify map localization is running (pose should be stable)
    • Try "Localize on Map" in Diagnostics
    • Check for "Repairing navigation..." status in nav badge
