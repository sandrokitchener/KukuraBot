    Step-by-step instructions

    1. Start mapping mode

      Open the Mapping panel and click "Start mapping mode". This puts Cartographer into SLAM mode to build a new map.

    2. Walk robot around space slowly

      Use manual controls or carry the robot upright at a steady pace. Keep the LiDAR clear of obstacles. Walk the entire area you want to map.

    3. Return to starting area

      Bring the robot back to where you started mapping. This helps Cartographer close the loop and improve map quality.

    4. Save new map identity

      In the Mapping panel, click "Save new map identity". This saves the occupancy grid and assigns a unique map ID.

    5. Start localization on saved map

      Click "Localize on saved map". Cartographer switches to localization mode, matching the current LiDAR scan against the saved map.

    6. Set charger origin here

      Place the robot on its charger. Click "Set charger origin here". This establishes the (0,0) reference point for all waypoints.

    7. Carry/walk robot to waypoint spot

      Move the robot to the exact location where you want a waypoint (e.g., kitchen counter, living room couch).

    8. Wait for pose stable

      Wait until the pose indicator shows "waypointSafe". This means Cartographer has localized the robot reliably on the map.

    9. Save waypoint here

      Enter a waypoint name (e.g., "kitchen") and click "Save waypoint here". The current pose is saved with the map identity.

    10. Repeat for more waypoints

      Move to each waypoint location and repeat steps 7-9.

    11. Check waypoint readiness

      Click "Check waypoint readiness". This verifies all waypoints are valid and Nav2 is ready.

    12. Recapture stale waypoints if needed

      If any waypoints show as stale (map identity mismatch), click "Recapture" next to each one and re-save at the correct location.

    13. Start waypoint navigator

      In the Diagnostics drawer, click "Start waypoint navigator". This launches Nav2 with the saved map and waypoints.

    14. Say "go to kitchen"

      Use voice or text to command the robot to navigate to a waypoint. The robot will plan a path and walk there.

    Troubleshooting

    Robot won't start mapping
    • Check LiDAR is connected and spinning
    • Verify DOGZILLA IP is set in Diagnostics drawer
    • Run "Check network" and "Check robot link" in Diagnostics
    Pose not stable (not waypointSafe)
    • Ensure robot is on a flat, stable surface
    • Check LiDAR has clear view of surroundings
    • Wait 10-15 seconds for Cartographer to converge
    • Try restarting map localization in Diagnostics
    Waypoints show as stale
    • Map identity changed (new map saved)
    • Click "Recapture" next to each stale waypoint
    • Re-save waypoint at the correct location
    Nav2 won't start
    • Check navigation chain health dots in Robot Info panel
    • Verify map localization is running (pose should be stable)
    • Try "Restart map localization" in Diagnostics
    • Check for "Repairing navigation..." status in nav badge
